# Jali core review · `93526af`

## Verdict

**Hold 1.0.** The pure layout engine, sticky folds, typed refusals, and memory ports are worth keeping. The release blockers are wrong-object draft restoration, saved layouts that crash or produce invalid geometry, and actions that can outlive a workspace and write to the next route.  
I reproduced `moveTab` and `pinTab` moving a divider in a crowded layout. The warning is reporting a real geometry change.  
The recorded packed baseline is **52.4 KiB gzip** for minimal core. A fresh in-memory source build measured **53.6 KiB**. A materially smaller build needs feature boundaries at composition time.  
Read-only verification passed **1,278 unit tests**, **14 docs reference tests**, both project typechecks, and the generated-docs check. Vitest used the threaded pool with caches disabled. Bundle measurements used source entries, and the Pop out proposal has yet to be verified in Chromium.

## Target architecture

- **One immutable workspace snapshot and one authoritative layout projection.** Keep the canonical tree, fitting policy, and pure layout operations. Give deliberate stacks stable slot identity, keep tab order independent of slot sizing, and record the destinations of sticky folds. Reuse the projection for model queries, commands, permissions, and drag previews.
- **One action and commit path.** Keep `apply`’s policy table and its intent replay after a question. Give each invocation a typed result, input source, and lifetime. Commit before publishing events, drain event batches in commit order, and make `destroy()` cancel outstanding work across all ports.
- **Explicit boundaries for effects and optional features.** Compose browser history, keyboard and focus, persistence, and window surfaces around the headless workspace. Keep curated pages and agents opt-in. Make the full React setup compose the features it offers today, with statically selectable feature groups for hosts that use their own chrome. Preserve the existing interaction and layout policies through that split.
