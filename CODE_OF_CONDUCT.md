# Code of conduct

Jali follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, and keep criticism to the work.

It applies in the repository's issues, pull requests and discussions, and wherever someone speaks for the project.

To report behaviour that breaks it, write to the maintainer at the address on [their GitHub profile](https://github.com/ramiz-rahman). Reports are kept private, and the maintainer decides what follows, from a reminder to a ban, as the Covenant's enforcement guidelines describe.
