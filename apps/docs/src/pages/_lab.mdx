## Callouts

<Callout title="A note">Folding never closes a pane. A folded pane is a tab of its neighbour until there is room again.</Callout>

<Callout type="tip">Give a list kind a smaller `width.min` than its detail, so the list stays when the window narrows.</Callout>

<Callout type="warning" title="Unsaved work">Report it with `useUnsaved("an edited query that has not run")`, and clear it with `null` once it is saved.</Callout>

## Code

```tsx filename="src/kinds.tsx" highlight="3-6"
import { definePane } from "@jali/react";

export const order = definePane("order", {
  params: { id: Number },
  title: ({ id }) => `Order ${id}`,
  width: { min: 280 }, // narrower than this, the pane folds into a tab
  Component: ({ params }) => <article>Order {params.id}</article>,
});
```

```css
@layer theme, base, jali, components, utilities;

```

A fenced block:

```ts
import { createJali, row } from "@jali/core";

const jali = createJali({
  panes: [order, customer],
  layout: row(order({ id: 1 }), customer({ id: 7 })), // kept in the address
});
```

## Table and lists

| Option | Type | What it does |
|---|---|---|
| `width.min` | `number` | Narrower than this, the pane folds into a tab. |
| `height.min` | `number` | Shorter than this, the pane folds. |
| `paneCap` | `number` | The most panes on screen at once. Default `8`. |
