## Callouts

<Callout title="A note">Folding never closes a pane. A folded pane is a tab of its neighbour until there is room again.</Callout>

<Callout type="tip">Give a list kind a smaller `minWidth` than its detail, so the list stays when the window narrows.</Callout>

<Callout type="warning" title="Unsaved work">Report it with `setUnsaved("an edited query that has not run")`, and clear it with `null` once it is saved.</Callout>

## Code

```tsx filename="src/kinds.tsx" highlight="3-6"
import { definePaneKind } from "@jali/react";

export const order = definePaneKind({
  kind: "order",
  title: (ref) => `Order ${ref.params.id}`,
  ref: (params) => ({ kind: "order", params }),
  minWidth: 280, // narrower than this, the pane folds into a tab
  minHeight: 160,
  Component: ({ ref }) => <article>Order {ref.params.id}</article>,
});
```

## Table and lists

| Option | Type | What it does |
|---|---|---|
| `minWidth` | `number` | Narrower than this, the pane folds into a tab. |
| `minHeight` | `number` | Shorter than this, the pane folds. |
| `paneCap` | `number` | The most panes on screen at once. Default `8`. |
