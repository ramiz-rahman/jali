---
title: Use Jali with Chakni
summary: Share one theme between Jali and Chakni, its sister library for collections.
---

Chakni is Jali's sister library for collections, such as lists and tables. Jali lays out the panes around them. The two meet in the **theme**. Neither package imports the other.

A list inside a pane tells Jali its current item with `select(ref)`, and `peek(ref)` shows an item in the peek sheet: see [Define a pane kind](/guides/pane-kinds).

## One theme for both

Jali's Tailwind bridge reads the token names Chakni reads: `--color-primary`, `--color-card`, `--color-border`, `--radius-card` and the rest. Import it, and an app themed for Chakni gets Jali in the same theme:

```css
@layer theme, base, jali, components, utilities;
@import "tailwindcss";
@import "jali/styles.css";
@import "jali/tailwind.css";
```

Jali's dark mode also follows Chakni's `.dark` and `.light` classes. See [Theming](/guides/theming).
