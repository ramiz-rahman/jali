The agent bridge: an AI agent inside your app reads the layout as data and changes it through the same actions a person's clicks and keys run. It has an entry of its own, so an app without an agent ships none of it. The task guide is [Let an agent arrange panes](/guides/agents).

```ts
import { createAgent } from "jali/agent";
```

## The bridge

<Entry name="createAgent" kind="function" from="jali/agent" signature={`createAgent(jali: AnyJali, options?: AgentOptions): JaliAgent`} example={agentCode} exampleFile="agent.ts">

Makes an agent bridge for one instance. The agent sees a snapshot and runs steps; your app decides which actions it may use (`actions`), asks about each step (`allow`), and chooses whether Jali arranges the panes after the agent's changes (`arrange`). Every change it makes carries `input: "agent"` in Jali's events. A close that would lose unsaved work still asks the person.

<Params>
<Param name="jali" type="AnyJali" required>The instance, from `createJali`.</Param>
<Param name="options" type="AgentOptions">What the agent may do. See <Ref to="AgentOptions" />.</Param>
</Params>

<Returns type="JaliAgent">See <Ref to="JaliAgent" />.</Returns>

</Entry>

<Entry name="JaliAgent" kind="type" from="jali/agent" signature={`interface JaliAgent`} compact>

What `createAgent` returns.

<Params title="Fields">
<Param name="snapshot" type="() => AgentSnapshot" required>The layout as data, now. See <Ref to="AgentSnapshot" />.</Param>
<Param name="act" type="(request: { steps: AgentStep[] }) => AgentResult" required>Run steps in order, stopping at the first refusal. Each step's refs are checked against their kinds before anything runs.</Param>
<Param name="tools" type="() => AgentTool[]" required>`jali_snapshot` and `jali_act`, as tools for a model: each with a description, a JSON Schema of its input and `execute`. The descriptions list the actions you allowed.</Param>
<Param name="registerTools" type="(context?: ModelContextLike) => () => void" required>Offers the same tools to the browser's own agent through WebMCP (`navigator.modelContext`, an experimental API), or to `context`. Returns the function that withdraws them. Does nothing where the browser has no such agent.</Param>
</Params>

</Entry>

<Entry name="AgentOptions" kind="type" from="jali/agent" signature={`interface AgentOptions`} compact>

The options of <Ref to="createAgent" />.

<Params title="Fields">
<Param name="actions" type="readonly AgentAction[]" default="every action in AGENT_ACTIONS">The actions the agent may use, by name.</Param>
<Param name="allow" type="(step: AgentStep) => boolean | string | void">Asked before each step. `false`, or a reason, refuses it, and the agent hears the reason; anything else allows it.</Param>
<Param name="arrange" type={`"when-asked" | "after-changes"`} default={`"when-asked"`}>Whether Jali arranges the panes after the agent's changes. `"when-asked"`: only when the agent runs `autoLayout`. `"after-changes"`: also after every `act` that opened or closed panes, unless the agent chose the layout itself in that turn. `allow` is still asked, as `autoLayout` with no arguments.</Param>
</Params>

</Entry>

## Actions and steps

<Entry name="AGENT_ACTIONS" kind="constant" from="jali/agent" signature={`const AGENT_ACTIONS: Record<AgentAction, string>`} compact>

Every action an agent can be given, each with a line that says what it does and what its arguments are, for the agent to read: `focus`, `toggleZoom`, `openBeside`, `openHere`, `peek`, `closePeek`, `select`, `setKept`, `addTab`, `close`, `closeTabs`, `undo`, `tuck`, `putBack`, `move`, `swapWithNext`, `mergeInto`, `unmerge`, `moveTab`, `setPinned`, `preset`, `resetLayout`, `autoLayout`, and a curated page's `page.open`, `page.leave`, `page.setMode`, `page.showView` and `page.showItem`. Removing a pane with no undo (`remove`), renaming, the dialogs and the person's settings are never offered.

</Entry>

<Entry name="AgentAction" kind="type" from="jali/agent" signature={`type AgentAction = keyof typeof AGENT_ACTIONS`} compact>

The name of an action an agent can use.

</Entry>

<Entry name="AgentStep" kind="type" from="jali/agent" signature={`interface AgentStep { action: AgentAction; args?: unknown[] }`} compact>

One thing for the agent to do: an action and its arguments, in order. A pane argument is a pane's id, or the ref of the object it shows (`{ kind, params }`).

<Params title="Fields">
<Param name="action" type="AgentAction" required>Which action.</Param>
<Param name="args" type="unknown[]">Its arguments, as `AGENT_ACTIONS` describes them.</Param>
</Params>

</Entry>

<Entry name="AgentResult" kind="type" from="jali/agent" signature={`interface AgentResult`} compact>

What `act` returns.

<Params title="Fields">
<Param name="ok" type="boolean" required>Every step ran. Steps stop at the first refusal.</Param>
<Param name="steps" type="AgentStepResult[]" required>Each step that was tried, and how it went.</Param>
<Param name="snapshot" type="AgentSnapshot" required>The layout after.</Param>
</Params>

</Entry>

<Entry name="AgentStepResult" kind="type" from="jali/agent" signature={`interface AgentStepResult`} compact>

How one step went.

<Params title="Fields">
<Param name="action" type="string" required>The step's action.</Param>
<Param name="ok" type="boolean" required>It ran.</Param>
<Param name="reason" type="string">Why it was refused: Jali's own reason (`not-found`, `nothing-to-do` and the others of <Ref to="RefusalReason" page="/reference/core/types" />), `not-allowed` (by `actions` or `allow`), or `invalid` (a ref its kind can't read).</Param>
<Param name="message" type="string">The refusal in words, for the agent.</Param>
<Param name="auto" type="true">Jali ran it on its own after the agent's changes (`arrange: "after-changes"`).</Param>
</Params>

</Entry>

## What the agent sees

<Entry name="AgentSnapshot" kind="type" from="jali/agent" signature={`interface AgentSnapshot`} compact>

The layout as data, as `snapshot()` and the `jali_snapshot` tool return it.

<Params title="Fields">
<Param name="workspace" type={`{ width: number; height: number; view: "single" | "split"; focused?: string; page?: { mode: string; tab?: string } | null }`} required>The size of Jali's root, its view (`"single"` while a phone shows one pane at a time, else `"split"`), the focused pane, and the curated page's mode and view when one is open.</Param>
<Param name="panes" type="AgentPane[]" required>Every pane. See <Ref to="AgentPane" />.</Param>
<Param name="kinds" type="AgentKind[]" required>The kinds of pane the app can open. See <Ref to="AgentKind" />.</Param>
<Param name="presets" type="{ id: string; label: string }[]" required>The presets, in menu order.</Param>
<Param name="actions" type="Record<string, string>" required>The actions this agent may use, with what each does.</Param>
<Param name="arrange" type={`"when-asked" | "after-changes"`} required>The `arrange` option in use.</Param>
</Params>

</Entry>

<Entry name="AgentPane" kind="type" from="jali/agent" signature={`interface AgentPane`} compact>

One pane, as the agent sees it.

<Params title="Fields">
<Param name="id" type="string" required>Its id in the layout.</Param>
<Param name="kind" type="string" required>Its kind.</Param>
<Param name="title" type="string" required>Its title, as the person sees it.</Param>
<Param name="params" type="ObjectRef['params']" required>What it shows.</Param>
<Param name="state" type="AgentPaneState" required>Where it is. See <Ref to="AgentPaneState" />.</Param>
<Param name="focused" type="true">It has focus.</Param>
<Param name="zoomed" type="true">It is maximised.</Param>
<Param name="tabs" type="string[]">The ids of the panes in its tab group, in order, when it has one.</Param>
<Param name="pinned" type="true">Its tab is pinned.</Param>
<Param name="kept" type="true">It is kept on its object.</Param>
<Param name="linkedTo" type="string">The pane it was opened from.</Param>
<Param name="follows" type="true">It follows the selection of `linkedTo`.</Param>
<Param name="unsaved" type="string">Its unsaved work, in the pane's words: closing it asks the person.</Param>
<Param name="notAllowed" type="string[]">The controls your app doesn't allow for it (`allow`); asking for them is refused.</Param>
<Param name="activity" type="string">Its activity (`"loading"`, `"working"`, `"live"` and the others), when it reports one.</Param>
</Params>

</Entry>

<Entry name="AgentPaneState" kind="type" from="jali/agent" signature={`type AgentPaneState = "shown" | "tab" | "folded" | "tucked" | "hidden"`} compact>

Where a pane is: on screen, behind another tab, folded for lack of room, tucked by the person, or hidden by a curated page.

</Entry>

<Entry name="AgentKind" kind="type" from="jali/agent" signature={`interface AgentKind`} compact>

A kind of pane, as the agent sees it.

<Params title="Fields">
<Param name="kind" type="string" required>Its name.</Param>
<Param name="params" type="Record<string, string>" required>Each param: `number`, `string`, `boolean` or `one of: a, b`, with `?` when a ref may leave it out. A kind whose params are a Standard Schema is one entry, `params`, "an object (vendor schema)".</Param>
<Param name="minWidth" type="number" required>Its `width.min`.</Param>
<Param name="comfortableWidth" type="number">Its `width.comfortable`, when it has one.</Param>
</Params>

</Entry>

## Tools

<Entry name="AgentTool" kind="type" from="jali/agent" signature={`interface AgentTool`} compact>

A tool for a model, in the shape MCP and WebMCP use.

<Params title="Fields">
<Param name="name" type="string" required>`jali_snapshot` or `jali_act`.</Param>
<Param name="description" type="string" required>What it does, with the allowed actions and their arguments.</Param>
<Param name="inputSchema" type="Record<string, unknown>" required>The JSON Schema of its input.</Param>
<Param name="execute" type="(input: unknown) => Promise<{ content: { type: 'text'; text: string }[] }>" required>Runs it, and returns its result as text content.</Param>
</Params>

</Entry>

<Entry name="ModelContextLike" kind="type" from="jali/agent" signature={`interface ModelContextLike`} compact>

The part of WebMCP's `navigator.modelContext` that `registerTools` uses. Pass your own for a test, or for another agent host with the same shape.

<Params title="Fields">
<Param name="registerTool" type="(tool: AgentTool) => unknown">Offer one tool.</Param>
<Param name="unregisterTool" type="(name: string) => unknown">Withdraw one tool.</Param>
<Param name="provideContext" type="(context: { tools: AgentTool[] }) => unknown">Offer every tool at once.</Param>
</Params>

</Entry>
