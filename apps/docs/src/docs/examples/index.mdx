Each one is a whole app, not a demo of one feature, and each runs here in your browser with nothing to install. Each has a page with three things it shows about Jali, every one a link that opens the app in the state that shows it. The source of every app is in [Jali's repository](https://github.com/ramiz-rahman/jali/tree/master/examples), built on the public API alone.

## The smallest app

`examples/minimal` is the app the [Quickstart](/get-started/quickstart) builds: one kind of pane, a note, with a button that opens the next note beside it. It is one file, `src/main.tsx`, with a few lines of CSS. Run it with `pnpm minimal` at the repository's root, then [localhost:5310](http://localhost:5310). Start there, then read [Define a pane kind](/guides/pane-kinds) to add your own.
